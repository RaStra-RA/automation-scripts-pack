# 🗂️ Automation Scripts Pack

5 Python scripts to automate common computer tasks — simple, clean, and beginner-friendly.

## 📁 Scripts Included

| # | File | Description |
|---|------|-------------|
| 01 | `sort_files_by_type.py` | Sorts files into subfolders by extension (PDF, JPG, TXT…) |
| 02 | `rename_photos_by_date.py` | Renames photos using EXIF or modified date |
| 03 | `bulk_pdf_merger.py` | Merges all PDFs in a folder into one file |
| 04 | `folder_structure_generator.py` | Creates a folder with standard subfolders |
| 05 | `image_resizer.py` | Resizes all images to a set width, keeping proportions |

## ⚙️ Requirements

- Python 3
- `pip install Pillow PyPDF2`

## ▶️ How to Run

**Windows:**
```bash
python scriptname.py
```
**Mac/Linux:**
```bash
python3 scriptname.py
```
